# Clair Desktop Windows 试用版 0.2.1

双击 `clair-desktop.exe`，可选文件夹，也可用“导入文件”从任意位置多选 FLAC、MP3、WAV；来源会记住，失联文件保留记录。此便携包不要求安装 Qt、Node.js 或单独启动 Web 服务。“打开 Web 版”默认启动仅监听本机的内置静态页面入口；桌面播放不依赖它，Web 端数据与桌面曲库暂不互通。

本版是**供测试反馈的原生预览版，不是最终成品**。新增歌词页、歌词浮窗、同名本地 LRC/手动 LRC、用户主动触发的 LRCLIB 歌词候选搜索；显示歌名/歌手编辑、可选的磁盘文件重命名；文件夹/艺术家/专辑分组及顺序、列表循环、单曲循环、组内随机。显示信息保存在用户设置中，不写音频标签；**只有点击“重命名文件”会改磁盘文件名**。重命名前建议备份重要文件。自动语音识别歌词、音频指纹识别歌名、图片组主题/裁剪、标签写入、收藏同步和跨平台正式安装器仍未实现。

直接解压整个压缩包再运行，不要只取出 EXE；运行库和 `qml/`、`platforms/` 等目录必须保留在一起。若媒体无法播放，请记录文件格式、Windows 版本和错误提示；不同平台的编解码与输出设备仍需验证。

源码与测试位于 Clair 仓库 `desktop/`；第三方许可证与来源见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。Windows x64 已通过构建、单元测试和冷启动测试；歌词联网搜索及不同音频设备的主观听感请实际试用反馈。macOS/Linux 需使用各自的包，不可直接运行此 EXE。**你确认试用结果前不会提交 Gitee/GitHub PR。**
