# Clair Desktop Windows 试用版 0.3.9

0.3.9 增加保守的转写缓存整理：当自动草稿缓存超过 100 MB 或 256 项时，仅整理超过一天且未被选为歌词的旧草稿；崩溃遗留的专用临时 WAV 目录仅在足够陈旧、文件名和内容明确、无运行中任务时清理。不会清理音频、手动导入的歌词或主题。内置 Web 静态服务会关闭超时的半请求连接，重复歌词搜索会取消上一请求。未做 24 小时压力测试，不能据此保证长时零泄漏。

双击 `clair-desktop.exe`，可选文件夹，也可用“导入文件”从任意位置多选 FLAC、MP3、WAV；来源会记住，失联文件保留记录。此便携包不要求安装 Qt、Node.js 或单独启动 Web 服务。“打开 Web 版”默认启动仅监听本机的内置静态页面入口；桌面播放不依赖它。

默认进入原生“正在聆听”页，左侧可切换音乐库和歌词；主界面恢复唱片、曲目信息、当前歌词和底部播放栏的 Web 版视觉层级，但不是 WebView。应用使用独立 Clair 唱片图标。实时频谱尚未接入音频信号，暂不展示伪动画。

**两版同步：**Web 和桌面版选择同一个本地音乐文件夹后，共用该目录 `.Clair/favorites.json`、`playlists.json`、`resume.json`。收藏、命名歌单及逐曲播放位置约每 2.5 秒刷新；“上次选中曲目”只在主动选曲时更新，不会因两版各自播放而来回跳。两版可以独立同时播放，切换时不会强行暂停另一版，也不会擅自自动播放；点击“接续共享进度”才接续。Web 必须在 Chrome/Edge 等支持文件夹读写 API 的浏览器中授权该文件夹，Codex 内置浏览器暂不支持该 API；只导入到桌面版的目录外单个文件、LAN 只读曲库及不同根目录之间暂不互通。新文件不会改写或删除原有 `.Clair/library.json` 和音频文件。损坏的共享 JSON 会拒绝覆盖并显示错误；请勿手工同时编辑这些文件。两进程**同一瞬间**修改同一共享文件尚无跨进程事务保护，可能发生后写覆盖先写；重要歌单请保留备份。

本版是**供测试反馈的原生预览版，不是最终成品**。提供歌词页、半透明置顶歌词浮窗、同名本地 LRC/手动 LRC、用户主动触发的 LRCLIB 歌词候选搜索；显示歌名/歌手编辑、可选的磁盘文件重命名；文件夹/艺术家/专辑分组及顺序、列表循环、单曲循环、组内随机。新增图片组主题（背景/封面/侧栏）、应用内框选裁剪和 AI skill 主题包导入；原图不会修改。显示信息保存在用户设置中，不写音频标签；**只有点击“重命名文件”会改磁盘文件名**。重命名前建议备份重要文件。

每首歌右侧“打开文件夹”会在文件管理器中定位原文件。需要删除原文件时，请在文件管理器操作，然后点击 Clair 的“刷新曲库”；“管理来源”中的“移除记录”仅取消导入，不删除磁盘文件。为便于文件管理器删除正在播放的曲目，打开该曲位置时 Clair 会先释放该曲的播放句柄。浮窗可按住歌词拖动；鼠标悬停显示上一首/播放/下一首、音量和底色透明度控制。点击“锁定”后浮窗支持鼠标穿透；在主窗口“歌词”页点“解锁浮窗”，也可用“浮窗归位”找回窗口。透明度和音量会记住。

歌曲识别：选中曲目 →“编辑曲目”→“按音频指纹匹配歌名”，需自行安装 Chromaprint `fpcalc` 并输入自己的 AcoustID API key；只给出候选，点击候选才保存显示名。歌词离线转写：在“歌词”页点“离线转写”→“开始转写”，已内置 CPU 版 whisper.cpp 及约 32 MB 的多语种 tiny-q5_1 模型，不需要选择 FFmpeg 或模型；Qt Multimedia 负责本机音频解码。任务可取消，结果是**需人工校对的草稿**；不承诺歌词准确率，纯器乐和强伴奏可能产生幻觉。“高级设置”仅供自定义识别程序/模型。详见包内 `TRANSCRIPTION.md`。主题包制作见 `THEMES.md` 与 `theme-skill/`。

0.3.4 起修复了部分 MP3 在解码器被强制请求 16 kHz 单声道时返回空数据的问题：现在先按源格式解码，再在本机转为转写需要的 PCM。长曲目解码可能需要约一分钟或更久，界面会显示进度；“解码结果为空”不是“没有歌词”。0.3.6 修复同步竞态、切歌进度归属和重命名后共享路径迁移。0.3.7 增加视频文件名清洗后的歌词搜索、明显幻觉草稿拦截、歌曲语言选择，以及歌词右键校时入口。主题可导入 PNG/JPG/JPEG/BMP 原图，裁剪输出统一为 PNG；WebP/HEIC 暂不支持。0.3.8 修正为“以所选歌词为锚点整体平移”，句间时间差保持不变；图片导入会说明具体失败原因，并已用用户提供的 JPG 验证。AI 主题按钮先显示可复制的制作提示词，再从弹窗内导入 manifest.json。

直接解压整个压缩包再运行，不要只取出 EXE；运行库和 `qml/`、`platforms/` 等目录必须保留在一起。若媒体无法播放，请记录文件格式、Windows 版本和错误提示；不同平台的编解码与输出设备仍需验证。

源码与测试位于 Clair 仓库 `desktop/`；第三方许可证与来源见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。Windows x64 与 Linux 已通过本机构建和单元测试；macOS 尚需真实构建验证。指纹在线识别及不同音频设备的主观听感请实际试用反馈。本 Windows 包不可用于 macOS/Linux。**你确认试用结果前不会提交 Gitee/GitHub PR。**
