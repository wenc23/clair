# Clair Desktop Windows 试用版 0.3.2

双击 `clair-desktop.exe`，可选文件夹，也可用“导入文件”从任意位置多选 FLAC、MP3、WAV；来源会记住，失联文件保留记录。此便携包不要求安装 Qt、Node.js 或单独启动 Web 服务。“打开 Web 版”默认启动仅监听本机的内置静态页面入口；桌面播放不依赖它，Web 端数据与桌面曲库暂不互通。

本版是**供测试反馈的原生预览版，不是最终成品**。提供歌词页、歌词浮窗、同名本地 LRC/手动 LRC、用户主动触发的 LRCLIB 歌词候选搜索；显示歌名/歌手编辑、可选的磁盘文件重命名；文件夹/艺术家/专辑分组及顺序、列表循环、单曲循环、组内随机。新增图片组主题（背景/封面/侧栏）、应用内框选裁剪和 AI skill 主题包导入；原图不会修改。显示信息保存在用户设置中，不写音频标签；**只有点击“重命名文件”会改磁盘文件名**。重命名前建议备份重要文件。

歌曲识别：选中曲目 →“编辑曲目”→“按音频指纹匹配歌名”，需自行安装 Chromaprint `fpcalc` 并输入自己的 AcoustID API key；只给出候选，点击候选才保存显示名。歌词离线转写：在“歌词”页打开“离线转写”，自行选择 FFmpeg、whisper.cpp 的 `whisper-cli` 和兼容的多语种 ggml 模型。任务可取消，结果是**需人工校对的草稿**；本包不捆绑大模型/识别工具，也不承诺歌词准确率。详见包内 `TRANSCRIPTION.md`。主题包制作见 `THEMES.md` 与 `theme-skill/`。

直接解压整个压缩包再运行，不要只取出 EXE；运行库和 `qml/`、`platforms/` 等目录必须保留在一起。若媒体无法播放，请记录文件格式、Windows 版本和错误提示；不同平台的编解码与输出设备仍需验证。

源码与测试位于 Clair 仓库 `desktop/`；第三方许可证与来源见 `THIRD_PARTY_NOTICES.md` 和 `licenses/`。Windows x64 与 Linux 已通过本机构建和单元测试；macOS 尚需真实构建验证。指纹在线识别及不同音频设备的主观听感请实际试用反馈。本 Windows 包不可用于 macOS/Linux。**你确认试用结果前不会提交 Gitee/GitHub PR。**
